Ejercicio 12 - Reversibilidad

```prolog
replicar(X, N, L) :-
   length(L, N),
   listaDeTodasX(X, L).

listaDeTodasX(_, []).
listaDeTodasX(X, [X | XS]) :- listaDeTodasX(X, XS).
```

El predicado resulta ser reversible porque, aunque `N` y `L` vengan sin instanciar, los predicados que se usan internamente lo manejan bien. Veamos como:

- `length(L, N)` es reversible. Como no tiene un y `N` definido, lo que hace es ir generando listas de tamaño creciente. Es decir, genera: `[]`, `[_]`, `[_,_]`, etc. En estas listas, todos los elementos son variables libres al momento de la generación.
- `listaDeTodasX(X, L)` toma la lista `L` (que gracias a `length` tiene un tamaño fijo, pues se llama con la `L` despues de instanciar la lista) y unifica cada elemento suyo con `X`.

El combinar ambos predicados termina generando todas las listas de longitud `N` donde todos los elementos son `X`.

### Ejemplos con `replicar(+Elem, -N, -Lista)`:

```prolog
?- replicar(x, N, L).
L = [], N = 0 ;
L = [x], N = 1 ;
L = [x, x], N = 2 ;
L = [x, x, x], N = 3 ;
% Genera todas las longitudes posibles con elementos x

?- replicar(o, N, L).
L = [], N = 0 ;
L = [o], N = 1 ;
L = [o, o], N = 2 ;
L = [o, o, o], N = 3 ;
% Genera todas las longitudes posibles con elementos o
```
